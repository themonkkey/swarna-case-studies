# Case Studies · Swarna Andhra @2047

Standalone site for the capacity-building case studies of the Andhra
Pradesh Planning Department — the library page and all the slide decks,
each downloadable in English and Telugu. Carved out of the main Swarna
Andhra @2047 site (themonkkey/Version-2); this repo serves only the
case-study library and its decks.

Static site — no build step. Deploy root: repository root.
